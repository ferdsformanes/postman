# Guide: Create a Collection in Postman v12

Follow these simple steps to create and set up a new collection in Postman Version 12.

### Step 1: Open Your Workspace
* Open **Postman**.
* Click **Workspaces** at the top.
* Select your workspace.

### Step 2: Create the Collection
* Look at the left sidebar.
* Click the **`+` (plus)** icon next to **Collections**.
* A folder named *New Collection* will appear.

### Step 3: Name Your Collection
* Double-click *New Collection* in the sidebar.
* Type a new name for your project.
* Press **Enter** to save the name.

### Step 4: Add Requests
* Click the **three dots (`...`)** next to your collection name.
* Select **Add request**.
* Type your API URL and click **Save**.
